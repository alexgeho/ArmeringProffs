# ТЗ: анимированные иллюстрации для страниц услуг

## Цель
Сделать на каждой странице услуги (`/tjanster/[slug]`) анимированную техническую иллюстрацию, которая за 3–5 секунд объясняет, что мы делаем. Сайт B2B (производство арматуры), покупатели — прорабы, закупщики, конструкторы. Нужно выглядеть инженерно и надёжно, без игрушечности.

## Контекст (прочитай сначала)
- `CLAUDE.md`, `AGENTS.md`, `STATUS`/handoff в docs — правила проекта.
- `config/services.ts` — услуги: `armeringsmontage`, `bockningslista`.
- `app/tjanster/[slug]/page.tsx` — шаблон страницы услуги.
- `components/illustrations.tsx` — там уже есть inline-SVG иллюстрации в стиле бренда (RebarCageIllustration, CoverLayerDiagram, BendingShapesDiagram, MeshOverlapDiagram...). **Новые анимации делать в том же стиле и в том же подходе.**
- Палитра бренда: оранжевый `#ea580c` + slate (`#334155`), светлый фон.

## Стиль: «СТАЛЬНОЙ» (важно)
- Стержни и сетки выглядят как **настоящая сталь**: `linearGradient` поперёк прутка (тёмный край → светлый блик → тёмный край), холодные серо-стальные тона (напр. `#475569` → `#cbd5e1` → `#334155`), лёгкий синеватый отлив.
- **Рифление (kamstål):** тонкие косые рёбра по прутку (pattern или короткие штрихи) — на крупных планах обязательно.
- Изометрия, аккуратные мягкие тени только под объектом (одна `feDropShadow`/эллипс, без драматизма).
- Анимированный **блик**: по стали один раз пробегает световая полоса (gradient offset / маска) — «металл сверкнул».
- Оранжевый `#ea580c` — ТОЛЬКО акценты: точки вязки, выделение, размерные линии/подписи. Сталь не красить в оранжевый.
- Бетон/опалубка — светло-серые плоскости, нейтрально, чтобы сталь была главной.
- Существующие плоские иллюстрации в `illustrations.tsx` не переделывать; новые анимации делать в стальном стиле.

## Технический подход
- **Inline SVG + CSS-анимации** (keyframes, `stroke-dasharray`/`stroke-dashoffset` для «прорисовки» линий, `transform` для движения). Без Lottie, без GIF/видео, без новых npm-зависимостей.
- Анимировать только `transform` и `opacity` (+ stroke-dashoffset) — без layout-сдвигов, CLS = 0.
- Запуск при появлении в зоне видимости (IntersectionObserver в маленьком client-компоненте), проигрыш 1 раз, затем статичный финальный кадр. Никаких бесконечных циклов, кроме очень тонких (опционально).
- `@media (prefers-reduced-motion: reduce)` → сразу финальный кадр без анимации.
- Финальный кадр должен быть полноценной статичной иллюстрацией (SSR/статический экспорт — сайт собирается в `out/`).
- Размер: каждый компонент < ~6 KB, `aria-hidden` или осмысленный `role="img"` + `aria-label` на шведском.
- Подписи/размеры (c/c 150, täckskikt 30 mm, Ø12) — SVG `<text>` в коде, НЕ в сгенерированной картинке.

## Сцены (по услугам)
1. **armeringsmontage** — «вязка на месте»: опалубка плиты в изометрии → последовательно укладываются нижние стержни, затем поперечные (сетка прорисовывается), появляются дистанционные подставки (distanser), в конце — точки вязки в узлах вспыхивают оранжевым. Подпись: c/c-шаг и täckskikt.
2. **bockningslista** — «от чертежа к стержню»: слева фрагмент чертежа/таблицы bockningslista (строки появляются по очереди: pos, Ø, antal, form) → справа прямой стержень сгибается в форму из строки (напр. U-bygel / хомут) → рядом появляется размерная линия. Идея: «из вашего чертежа — готовая гнутая арматура».
3. Если в `config/services.ts` или `app/produkter` есть ещё услуги/продукты (klippt & bockat, armeringskorgar, armeringsnät, leverans) — предложи и сделай такую же сцену для каждой (напр. korg: стержни собираются в каркас; leverans: грузовик едет по контуру Швеции к точке).

## Recraft (опционально)
Recraft MCP подключён. Используй его только как **референс/эскиз** композиции (промпт на английском, «isometric illustration of ribbed steel rebar, realistic brushed metal steel look, cool grey steel tones, subtle highlights, light grey background, clean industrial style, no text, no people»). Финал — рукописный SVG-код, не растровая картинка (растр нельзя анимировать по частям и он тяжелее). Если сгенерируешь SVG в Recraft — упрости и почисти его вручную перед использованием.

## Не делать
- Clay/пластилин, мультяшность, люди, стоковые фото, яркие неметаллические цвета на стали.
- Не трогать существующие фото (hero, продукты) — анимации дополняют, а не заменяют.
- Не менять тексты услуг/SEO-мета.

## Приёмка
- `npm run lint` и `npm run build` зелёные.
- Проверить в браузере (dev): анимация запускается при скролле, 1 раз; reduced-motion показывает финал; на мобильном (375px) без горизонтального скролла, читаемые подписи.
- Lighthouse мобильный на странице услуги: CLS 0, производительность не хуже, чем до.
- Закоммитить с понятным сообщением, обновить STATUS/handoff (что сделано + компоненты). Push — по правилам проекта.
