## 🕵️ Конкуренты

### 1. Armeringdirekt (armeringdirekt.se) — webshop + Shopping
- Модель: **интернет-магазин с ценами** (вкл. moms), фид Google Shopping. Offert только на заказы > 50 000 kr.
- Цены-примеры: nät 5150 — 469 kr, 6150 — 650 kr, B-bygel 12mm — 62 kr, korg — 782 kr.
- **Frakt: från 1 249 kr** (диапазон 249–2999 kr). Срок 1–5 дней. **Север Швеции — только по запросу.**
- Сила: мгновенная онлайн-покупка, цены, скорость, Shopping-присутствие.
- **Слабости, которые бьём:** высокая фикс-доставка 1 249 kr (убивает мелкие/средние заказы);
  webshop **не покрывает Norrland**; мало инфо по кастомным bockning/спецификациям.

### 2. Stena Stål — ILF armering (stenastal.se) — quote, бренд
- ILF = «inläggningsfärdig armering» (готовая к укладке, kapat & bockat), консультативная/offert-модель.
- Плюс: только номинальный вес (без наценки за spill), бесплатные Typblad 2A шаблоны, экспертиза, крупный бренд.
- **Срок 10–12 рабочих дней (медленно).** Контент тонкий, конверсия через offert-форму.
- **Слабости, которые бьём:** долгий срок, тонкий/корпоративный контент, нет самообслуживания (калькулятор/мгновенная оценка).

### 3. Bromma Stål (brommastal.se) — Stockholm, quote
- 700+ размеров стали, свой цех + сварка (EXC3), «offertkorg». **Frakt фикс 1 500 kr/поставка.**
- **Слабости:** только **Стокгольм-регион**; нет прозрачных цен; klippt&bockad/korgar слабо промотированы; высокая фикс-доставка.
