Источник: `docs/SEO-KARNA-kommersiell.md` + GSC + Keyword Planner. Всего: **101 новая + 23 доработки = 124**.
Каждая страница — своя тема и свои данные (таблицы, нормы, схемы), без шаблонных клонов.

Картинки: SVG-схемы и таблицы; новые фото — только по BILDSTIL через контактный лист.

## Правило перелинковки: все страницы ведут на коммерческие
Каждая инфо-страница (волны 2–6) → 1 главная коммерческая цель: ссылка в первом экране + CTA-блок «Beställ» + ссылка в FAQ.
Коммерческая страница получает ≥5 входящих ссылок; инфо-страницы между собой — не больше 2–3 ссылок.
- Ø6–Ø32, B500B/K500C-T, förankring, bockningsradie → /produkter/armeringsjarn + klippt-och-bockad
- Nät 5150–10150, dubbelt nät, nätkalkylator, fiber vs nät → /produkter/armeringsnat
- Byglar U/B/N/C, S-hake, kantjärn → /produkter/byglar-och-hakar
- Husgrund, platta på mark, kantbalk, attefall, friggebod, uterum, carport, bastu, golvvärme → /produkter/grundarmering + villakorg
- Pelare, balk, hissgrop, bjälklag, balkong → /produkter/pelar-och-balkkorgar
- Stolpfundament, maskinfundament, platta på pålar, vindkraft → /produkter/palarmering + plintkorgar
- Pool, brunn/tank → /produkter/poolarmering
- Ritning, spec, typformer, ILF, armeringsplan → /tjanster/armeringsspecifikation + /tjanster/ilf-armering
- Najning, najtråd, täckskikt, kontroll → /produkter/najtrad-och-tillbehor + distanser
- Industri, lagerhall, stall, gödsel, B2B-отрасли → /armeringsleverantor
- Pris, prefab vs själv, kg/m³ → /armering-pris → /offert
Существующие 26 статей блога — то же правило (доработка в волне 1).
